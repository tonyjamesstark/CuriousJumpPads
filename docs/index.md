# CuriousJumpPads

Launch players across a map: commands that set player velocity, and jump pads that launch
whoever steps on them. Can aim at a landing point: give it the spot, and it works out the arc.

Paper/Purpur 26.2, Java 25.

- [Quick start](quick-start.md): install, then make a pad that lands players on a block.
- [Commands and permissions](commands.md): every command, permission and config key.
- [Command block design](command-blocks.md): pads built from vanilla command blocks.
- [Limits](limits.md): reach, accuracy and the velocity cap.
- [API reference](api/index.html): Javadoc for the plugin's public classes.

Source: <https://github.com/tonyjamesstark/CuriousJumpPads>
